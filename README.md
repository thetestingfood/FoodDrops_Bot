# FoodDrops Discord Bot

## 🛠️ Deliverables
- Order Ticket System:
   > /panel creates a customizable panel with a “Create Order Ticket” button.
   > Tickets are private channels created under the same category as the ticket button.
   > Users submit forms with group link, full name, Apt/Floor/Suite, tip, and delivery instructions.
   > Tickets include interactive buttons: Claim, Complete, Close.

- Transcript System:
   > On Complete or Close, the bot generates a transcript.
   > Complete adds an order to the person who created the ticket.
   > Close does not add an order
   > Transcript is saved as a private GitHub Gist (no .txt in Discord).
   > The transcript message includes an embed and a "View Online Transcript" button.
